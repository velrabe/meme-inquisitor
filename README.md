# Meme Inquisitor

Игра-шутер с волнами врагов и интеграцией GamePush.

## 🎮 Геймплей

- Враги идут сверху вниз волнами
- Игрок автоматически стреляет
- Управление: стрелки / A,D / мобильные кнопки / drag игрока
- Цель: не допустить врагов в красную зону внизу экрана
- За каждое убийство +1 очко
- Сохранение лучшего счета через GamePush

## 📁 Структура проекта

```
/public
  index.html          - Главная HTML страница
  style.css           - Стили игры
  /img                - Спрайты (pope.png, sahur.png)
  
/src
  main.js             - Главный игровой цикл
  config.js           - Константы игры
  renderer.js         - Canvas и отрисовка
  input.js            - Управление (клавиатура, touch, drag)
  state.js            - Состояния игры
  world.js            - Контейнер игровых объектов
  player.js           - Логика игрока
  bulletPool.js       - Пули с object pooling
  enemyPool.js        - Враги с object pooling
  spawner.js          - Спавн волн врагов
  collisions.js       - Система столкновений
  ui.js               - UI элементы
  storage.js          - Интеграция с GamePush
```

## 🚀 Запуск игры

### Вариант 1: Live Server (VSCode)
1. Установите расширение "Live Server" в VS Code
2. Откройте `/public/index.html`
3. Нажмите "Go Live" в правом нижнем углу

### Вариант 2: Python HTTP Server
```bash
cd public
python3 -m http.server 8000
```
Откройте `http://localhost:8000` в браузере

### Вариант 3: Node.js HTTP Server
```bash
npx http-server public -p 8000
```
Откройте `http://localhost:8000` в браузере

## ⚙️ Настройка

Все параметры игры находятся в `/src/config.js`:

- Скорость игрока и врагов
- Частота стрельбы
- Интервалы спавна
- Размеры хитбоксов
- И многое другое

## 🎯 Управление

### Десктоп:
- **Стрелки ← →** или **A / D** - движение влево/вправо

### Мобильные:
- **Полупрозрачные стрелки** - нажать и удерживать
- **Drag** - зажать и перетащить игрока пальцем

## 🏆 GamePush интеграция

Игра автоматически сохраняет лучший счет в GamePush.
Fallback на localStorage если GP недоступен.
